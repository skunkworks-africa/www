Windows Server licensing explained

How Windows Server core licensing works

01

Count physical cores

Licensing by physical cores covers every physical processor core, subject to a minimum of eight core licences per processor and sixteen per server.

02

Account for virtualisation

Standard grants two operating system environments per full core-licensing layer. Datacenter grants unlimited virtualisation rights on a fully licensed physical server.

03

Select licence packs

Microsoft documents core licences in two-core and sixteen-core packs. An estimator can combine pack sizes; exact product eligibility and purchasing terms must be verified.

Frequently asked licensing questions

Do hyperthreaded or logical processors count as physical cores?

No. Physical-core licensing is based on physical processor cores, not simultaneous multithreading threads.

How do I license more than two Windows Server VMs on Standard?

Under physical-core licensing, each additional set of two Windows Server operating system environments requires a full additional licensing layer across the server's cores. A physical host OS used solely to host and manage the VMs may have an additional permitted use right.

Can I license Windows Server by individual virtual machine?

For qualifying subscriptions or licences with active Software Assurance, Microsoft allows per-VM licensing. Each licensed VM needs at least eight core licences, with at least sixteen core licences per customer. Separate rights apply to any physical operating system.

Are Windows Server Client Access Licences included?

No. Windows Server CALs, Remote Desktop Services CALs and other access rights must be assessed separately according to actual users, devices and the Product Terms.

Does this calculator cover clusters, failover, Azure Arc or special licensing programmes?

No. Advanced deployment rights depend on the agreement, workload mobility, Software Assurance, hardware allocation and programme. Request a technical licensing assessment for these cases.

Official sources: Microsoft Windows Server 2025 licensing guidance and Microsoft Product Terms. In the event of a conflict, the applicable agreement and Product Terms control.
