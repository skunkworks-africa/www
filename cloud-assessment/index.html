Cloud productivity sizing

Microsoft 365 & Google Workspace information-gathering form

Complete this assessment so Skunkworks Africa can identify the right licensing mix, migration scope, security requirements and implementation effort for your organisation.

Typical completion time: 5–10 minutes. You do not need to know exact licence names.

Fields marked (required) must be completed. You can leave the other fields blank if you are unsure.
